# Sistema de Controle de Manutenção de Peças

Projeto para controle de manutenção de equipamentos, peças e fornecedores.

## Estrutura do Projeto
- `main.py`: Ponto de entrada do sistema.
- `config/`: Configurações de banco de dados.
- `src/`: Lógica de negócio dividida por módulos.
- `web/`: Interface web (em desenvolvimento).
