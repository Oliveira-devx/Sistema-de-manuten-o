# Interface Web - Sistema de Manutenção

Esta pasta conterá a futura interface do usuário.

## Organização:
- `templates/`: Arquivos HTML (estruturas de página).
- `static/css/`: Estilos visuais.
- `static/js/`: Scripts de interação.
- `static/images/`: Ativos visuais.

**Atenção:** A interface será integrada ao Python via Flask/FastAPI posteriormente.
